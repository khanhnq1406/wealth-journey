## Overview

When tabs overflow the tab bar on mobile or narrow viewports, users see no visual hint that more tabs exist. This adds a gradient fade + clickable chevron buttons (`<` / `>`) to the `TabBar` underline variant so users can discover and navigate hidden tabs. Pill variant is unaffected.
